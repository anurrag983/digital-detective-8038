## 4. My understanding

### Task 1.1 — Trace one activity using IPOS (Taking and saving a photo)
| Stage | What happens in your example? | Possible hardware / component |
| :--- | :--- | :--- |
| **Input** | I press the shutter button on screen to take a picture. | Touchscreen / Camera sensor |
| **Processing** | The phone's processor handles the image data, adjusts lighting, and compresses it into a JPG file. | CPU / Image processor and RAM |
| **Output** | The photo appears right away on my screen so I can see how it looks. | Phone display screen |
| **Storage** | The JPG file gets saved onto the internal flash storage so it stays there even after the phone turns off. | Internal flash storage / SSD |

*Explanation:* It starts with physical light entering the camera sensor (input), which the CPU and RAM turn into digital bits and compress (processing). Then the screen displays the final picture to me (output), and the file gets written to permanent storage so it isn't lost.
